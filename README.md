# 💱 Currency Converter

A simple and responsive web-based **Currency Converter** that allows users to convert amounts between different currencies using live exchange rates.

## 🌟 Features

- 💰 Convert currencies in real time
- 🌍 Supports multiple currencies
- 🔄 Swap source and target currencies
- 📊 Displays the current exchange rate
- ⚡ Uses a live exchange-rate API
- 📱 Responsive design for mobile and desktop
- ✅ Input validation
- ⏳ Loading indicator
- ❌ Error handling
- 🎨 Clean and modern user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Frankfurter API
